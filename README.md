# Theatre of Mind

Модуль для [Foundry VTT](https://foundryvtt.com/) для игры в театре воображения. ГМ выводит портреты персонажей поверх сцены, как в визуальной новелле, и меняет локации, а игроки видят это на своих экранах. От игровой системы модуль не зависит.

Управляет сценой только ГМ, игроки смотрят.

## Возможности

- **Портреты:** эмоции, дыхание, фокус на говорящем, поворот, ручная позиция и масштаб. Тон портретов подстраивается под темноту сцены.
- **Библиотека персон и локаций:** папки, избранное, поиск и массовое создание из папки с картинками.
- **Смена локаций:** переход между фонами и название локации на экране.
- **Погода по месту:** в локации без галочки «На улице» погода сцены скрыта, на улице она снова видна. Саму погоду задаёт ГМ или другой модуль, например Simple Timekeeping.
- **Режиссёрские эффекты:** вспышка, тряска, удар сердца, помехи, занавес, бешенство, Рётшрек, воспоминание и замирание. Можно включить всем или одному игроку.
- **Интерфейс:** русский и английский.

## Установка

В Foundry откройте **Setup → Add-on Modules → Install Module** и вставьте ссылку на манифест в поле **Manifest URL**:

```
https://github.com/himselfego/theatre-of-mind/releases/latest/download/module.json
```

Обновляется модуль там же, кнопкой **Update**. Нужен Foundry VTT v14.

При первом запуске у ГМа модуль создаёт папку сцен **Theatre of Mind** и в ней сцену **Scene**. Портреты показываются только на этой сцене.

## Управление

Клавиши Shift, Alt и Ctrl можно поменять в настройках клавиш Foundry.

### Панель

- **Левая кнопка на карточке:** вывести персону на сцену или убрать её, а на вкладке «Сцена» включить или выключить локацию.
- **Правая кнопка на карточке персоны:** открыть редактор.
- **Средняя кнопка на карточке:** добавить в избранное или убрать из него.
- **Щётка:** очистить сцену от персон, а на вкладке «Сцена» снять локацию.
- **Значок книги:** открыть библиотеку.

Разворачивание панели открывает сцену театра у всех игроков. Смена локации убирает персон со сцены.

### Эффекты

Эффекты работают только на сцене театра.

- **Вкладка «Эффекты» на панели:** клик запускает эффект, повторный клик выключает длительный.
- **Список «Кому»:** всем или одному игроку. Занавес всегда для всех.
- **Щётка:** снять все эффекты.
- **Занавес:** у игроков чёрный экран, а ГМ видит сцену сквозь него и может её подготовить.
- **Клавиши:** их можно назначить в настройках клавиш Foundry.

Игрок может отключить у себя вспышки, тряску и помехи настройкой «Эффекты без вспышек и тряски».

### Портрет

- **Средняя кнопка:** поставить фокус, повторное нажатие снимает его.
- **Правая кнопка:** отразить по горизонтали.
- **Перетаскивание на другой портрет:** поменять их местами.
- **Shift при отпускании:** оставить портрет там, где он отпущен.
- **Alt или колесо при перетаскивании:** изменить масштаб, а с Alt ещё и наклон.
- **Ctrl и левая кнопка:** убрать портрет со сцены.
- **Наведение:** показать панель эмоций и имя.

Если выключить настройку «Сбрасывать позицию при отпускании», портрет остаётся там, куда его перетащили, а сбрасывается двойным щелчком.

### Библиотека

- **Вкладки вверху:** переключение между персонами и локациями.
- **Двойной щелчок по карточке:** вывести персону на сцену или применить локацию.
- **Перетаскивание карточки на папку:** переместить её в эту папку.
- **Правая кнопка на карточке или папке:** меню с редактированием и удалением.

### Игроки

Игроки видят портреты, эмоции и имена при наведении. Они могут приглушить портреты кнопкой на экране, полностью скрыть их в настройках и поменять размер имён. Размер портретов можно менять, если ГМ не задал общий.

## Разработка

Сборки у модуля нет: Foundry загружает файлы как есть. Node нужен только для скрипта синхронизации.

`npm run sync` копирует `scripts`, `styles`, `templates` и `lang` на ваш сервер Foundry по SSH, а `npm run sync:watch` делает это после каждого изменения. Адрес берётся из файла `.sync-target` в корне проекта (в git он не попадает), одна строка вида:

```
user@host:/путь/к/Data/modules/theatre-of-mind
```

При первой установке запустите `node tools/sync.mjs --init`: он создаст папку на сервере и скопирует `module.json`. После изменений обновите страницу мира (F5). Если менялся `module.json`, добавьте `--manifest` и перезапустите Foundry. Флаг `--clean` сначала удаляет на сервере прежние копии папок.

Релиз собирает GitHub Actions при пуше тега вида `v1.2.3`.
